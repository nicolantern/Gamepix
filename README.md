# Mini Games Arcade

Five vanilla-JS mini-games on one HTML page: Snake, Pong, Tic-Tac-Toe, Memory Match, Flappy Bird.

## Run

Open `index.html` in any modern desktop browser. No build, no server, no dependencies.
